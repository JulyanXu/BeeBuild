# BeeBuild v0.1.0 · 让熟悉的界面，重新发生

BeeBuild 的首个预览版本：36 个彩色光标，各自接手一小块内容，把文字、图片和控件重新画出来。

## 可以体验什么

- 三个中文可交互场景：设计笔记、长网页、应用文件列表。
- 36 个光标拥有独立的任务负责人和局部位置，文件按行分区，图标、名称、日期、类型分别施工。
- 滚动与动画同时进行，新内容出现后继续构建；已完成内容保留，光标持续待命。
- 底部磨砂控制条提供 0.5× / 1× / 2× / 3×、暂停/继续、当前视口重播及立即退出。
- 默认节奏保留可读的操作过程：各类动作约 210–990ms，最多 24 项可见任务同时进行，重叠内容依次绘制。
- 本地视频录制：主动选择浏览器共享画面，停止后预览、下载；优先 WebM，按浏览器能力回退到 MP4，无声音，不上传录制文件。

## 验证

38 项自动测试通过，覆盖动画时钟、速度切换、暂停/继续、连续滚动、任务归属、重叠互斥、重播、退出、录制生命周期和构建产物。生产构建与独立 Sites 打包检查通过。1× 调度基准中，48 项混合任务约 2.00 秒，105 项文件任务约 1.87 秒；真实页面时间取决于内容与浏览器帧率。

## 使用范围

这是视觉重建工具的浏览器交互原型，重画页面内的模拟场景。Agent 是动画调度器控制的视觉光标，当前没有真实 Mac 应用窗口捕获、系统全局快捷键或自主 AI 模型调用。录制需支持浏览器共享 API；当前没有 GIF 导出。

体验和本地运行方式见仓库 [README](https://github.com/JulyanXu/BeeBuild#readme)。交互节奏参考 [Swarm Rebuild](https://github.com/DhvanilPatel/swarm-cursors)，动画调度与呈现独立实现。
