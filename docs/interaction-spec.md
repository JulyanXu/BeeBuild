# BeeBuild 交互原型规格

本文记录当前 React 原型的设计与实现约定。视觉采用已选中的 Mac 窗口与底部悬浮控制条：浅暖色桌面、白色内容区、黄色主按钮、36 个彩色 Agent 光标。重画是已有界面的动画显现，不生成或修改软件。验收结果与剩余验证范围以 `design-qa.md` 为准。

## 窗口与场景

| 场景 | 可用交互 |
| --- | --- |
| 设计笔记 | 文件夹与笔记切换、长文滚动、收藏列表独立滚动、收藏切换；顶部搜索按笔记标题过滤当前文件夹。 |
| 长网页 | FIELDNOTES 的自然、设计、生活主题切换，文章收藏、相关文章跳转；搜索匹配文章内容并显示结果入口。 |
| 应用列表 | Finder 风格位置切换、文件选择与详情、列表/网格切换、收藏；顶部搜索按文件名过滤当前位置。 |

- 场景菜单切换窗口，并清空搜索与该场景的临时状态。
- 窗口标题栏的交通灯与编辑图标是视觉示意；顶部搜索、场景菜单、设置与使用说明可以操作。
- 笔记正文与网页均有足够长的内容；收藏列表等内部滚动区独立滚动，不把滚动继续传递给父区。
- 首次打开且未启用减少动态效果时，等待主图加载成功或失败后约 650 ms 自动开始演示。

## 播放控制与状态

底部控制条包含品牌与 36 光标提示、暂停/继续、速度、重播、录制和退出。退出后显示启动条，并保留录制入口。当前视口完成后仍保持播放态与「暂停」按钮，不自动切换到重播状态。

| 动作 | 当前实现 |
| --- | --- |
| 开始 | 重画当前视口，清空本次完成记录，先播放约 500 ms 光标聚集，再由 36 个光标协同施工。 |
| 暂停 | 停止动画时钟，保留当前位置与显现进度；未发生内容变化时，继续可从原进度恢复。 |
| 调速 | 支持 0.5×、1×、2×、3×，初始 1×。即时改变后续时间推进，不重置已完成进度；暂停时调速不会启动动画。 |
| 重播 | 只重新构建当前视口，保留视口外的完成记录；不重复入场聚集。暂停时点击重播会直接开始播放。 |
| 退出 | 立即取消帧与延迟任务，恢复元素原有 `opacity`、`clip-path`、`will-change`，清空任务与完成记录，回到可正常操作的界面。 |
| 视口完成 | 保持 `running`，36 个光标轻微巡游待命；新内容出现时继续施工，已完成区域不自动重画。完成状态由 `viewportComplete` 标识，不代表暂停或结束。 |

引擎状态为 `idle → intro → running`；`intro` 与 `running` 可进入 `paused`，继续时恢复原阶段。`viewportComplete` 表示当前可见任务已完成，播放时钟与待命光标继续运行。只有用户显式暂停冻结动画，退出则结束本次播放。施工速度受任务数量、依赖与所选倍率影响，36 个光标不等于 36 次模型调用。

## 滚动与内容变化

- 捕获窗口内所有滚动事件，包括嵌套区域。滚动只标记几何更新，在下一动画帧重新测量可见区域，时钟、光标与绘制进度持续推进。
- 既有任务更新位置与裁剪，保留已开始时间和进度；新进入视野的内容加入队列，已开始但移出视口的任务继续完成。不会因连续滚动反复从空白开始，也不等待滚动停止才恢复播放。
- 约 150 ms 的滚动结束计时只清除界面滚动提示，不控制动画调度。
- 暂停时仍允许滚动并更新几何、新任务队列，但不开始或推进绘制；按「继续」后沿保留的进度接续，不补播暂停期间的时间。36 个光标在暂停期间保持原位置，恢复播放时再对应到新的内容位置。
- 窗口尺寸变化采用同样的增量测量；播放保持连续，暂停状态也保持不变。
- 场景、搜索、笔记、文件选择与收藏等变化通过 `contentRevision` 使旧任务失效，清空旧完成记录。正在播放时重画新内容，暂停时等待继续，退出状态下不自动启动。
- 返回已完成区域时不重复施工；显式重播或内容变化会使相应记录失效。

## 视频录制与保存

录制是与动画分开的状态机：`idle → requesting → recording → stopping → ready`，取消、拒绝、环境不支持和编码失败均给出明确反馈。录制组件在播放与退出状态之间保持挂载，避免退出重画时丢失未保存视频。

1. 点击底部「录制」打开说明，明确建议共享当前 BeeBuild 标签页、无声音、本地处理。
2. 点击「选择标签页并录制」后，由浏览器原生共享选择器让用户选择来源；应用不能替用户批准共享。
3. 选择成功后开始计时。若重画尚未启动，则开始重画；已有播放进度保持不变。
4. 录制期间自由滚动、调速、暂停或退出重画，都会保留在真实录制画面中。暂停或退出重画不会停止录制；点击录制按钮的停止入口，或在浏览器中停止共享，才结束录制。
5. 结束后在面板预览视频并「保存视频」；可再次录制。关闭面板保留当前结果，刷新或离开页面会清除未保存结果。

- 使用浏览器 `getDisplayMedia` 与 `MediaRecorder`，优先 WebM（VP9/VP8），按浏览器实际编码能力回退到 MP4；扩展名跟随真实输出容器。当前没有 GIF 导出。
- 不请求音频；不上传录像数据。需要支持上述 API 的桌面浏览器和 localhost／HTTPS 安全上下文；浏览器或宿主环境禁用共享时展示不可用状态。
- 取消新的共享选择保留已有可下载视频。停止共享、录制失败和卸载必须释放媒体轨道；替换或丢弃结果时释放旧预览 URL。
- 浏览器共享选择器可能允许标签页、窗口或屏幕；实际录制范围以用户明确选择的对象为准。应用重画引擎仍只作用于页面内模拟场景。

## 快捷键与设置

- 默认快捷键为 `⌥⇧B`，仅在当前网页获得键盘事件时有效：未启动时开始，其余播放状态下退出。输入框、文本编辑区内不响应该组合键。
- 正常情况下，`Esc` 关闭菜单；有对话框时先关闭对话框，否则退出重画。即使焦点在搜索输入框中也可退出。
- 设置内可重新录制字母或数字组合键，必须包含 Option、Control 或 Command；Shift 可附加。录制期间按 `Esc` 仅取消录制。设置不写入持久化存储，刷新后恢复默认。
- 「默认速度」是本次预览的即时速度设置，不代表下一次打开时的持久偏好。
- 「减少光标动效」初始跟随系统 `prefers-reduced-motion`；开启后隐藏移动光标与施工覆盖层，保留逐块显现。此模式首次打开不自动播放。
- 对话框支持焦点循环、关闭按钮、点击背景关闭与 `Esc` 关闭。

## 实现接口与验证重点

- `SceneContent({ scene, searchQuery = '', onContentChange })` 渲染场景；内部内容变更调用 `onContentChange`。
- `useRebuild({ rootRef, sceneKey, contentRevision = 0 })` 返回状态快照、`viewportComplete` 与 `start/pause/resume/setSpeed/replay/exit`。
- 每个可重画节点使用唯一且稳定的 `data-build`；`data-kind` 为 `text/image/box/line`。避免父子节点同时标记；采集会求元素与所有滚动裁剪祖先的交集。
- 文字采用 DOM 行矩形推进裁剪与光标；图片由上向下显现，线条由左向右，控件在拉框后淡入。覆盖层不接管指针，底层场景仍可操作。
- `src/recording/` 管理录制控制器、React 接口与面板；它与绘制虚拟时钟独立。媒体权限请求只由用户操作触发，重画启动不能自动发起屏幕共享。

验收至少覆盖：36 个光标持续可见；四档速度不中断进度；视口完成后继续待命；连续暂停/继续；暂停后滚动；快速往返与惯性滚动不中断时钟；嵌套滚动；resize 不重启；播放中搜索/切换内容；只重播当前视口；退出后无残留样式；快捷键录制与刷新恢复；减少动效模式。录制另外验证取消/拒绝共享、开始与停止、浏览器结束共享、暂停重画但继续录制、本地预览/下载、真实格式可播放、失败清理与未保存结果保留。

本原型的重画只读取页面内三个模拟窗口的 DOM，不读取原生应用结构，不注册系统全局快捷键。录制仅获取用户通过浏览器明确选择共享的画面。没有原生窗口绑定、辅助功能权限集成、声音或模型调用；浏览器演示及编码单元测试不能作为原生 Mac 兼容性验证。
