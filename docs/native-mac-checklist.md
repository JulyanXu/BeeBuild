# BeeBuild 原生 Mac 实现验证清单

目标是把当前视口的 36 光标重画体验带到真实 Mac 窗口，并在滚动时持续播放。以下是待实现与待真机验证的建议，不代表浏览器原型已经具备这些能力。浏览器原型的用户授权录制功能也不等同于原生窗口捕获与覆盖。

## 建议的最小架构

- **SwiftUI**：设置、菜单栏入口、快捷键配置与权限说明。
- **AppKit**：与目标窗口对齐的无边框覆盖窗口，以及独立可交互控制条；动画层与控制条分别管理事件和窗口层级。
- **ScreenCaptureKit**：以指定窗口的实际像素为最终外观来源。窗口模式使用 `SCContentFilter(desktopIndependentWindow:)`；显示器模式按应用或窗口排除 BeeBuild 自身，避免覆盖层再次进入捕获。单帧分析可使用 `SCScreenshotManager`，滚动跟随需要持续帧源。[内容过滤](https://developer.apple.com/documentation/screencapturekit/sccontentfilter)、[单帧捕获](https://developer.apple.com/documentation/screencapturekit/scscreenshotmanager)
- **AX 增强**：在取得辅助功能信任后读取可用的文本、元素位置与尺寸，帮助分块；截图保留最终外观。属性不可用、调用失败或超时时回退到图像区域显现，不能把任意应用视为完整 DOM。[AX 属性读取](https://developer.apple.com/documentation/applicationservices/1462085-axuielementcopyattributevalue)、[文本范围矩形](https://developer.apple.com/documentation/applicationservices/kaxboundsforrangeparameterizedattribute)
- **调度器**：保留 36 光标、暂停、倍速与版本失效机制；不照搬浏览器节点引用。目标可见且捕获有效时，滚动与尺寸变化只更新任务几何，不停止虚拟时钟；新区域增量入队，已开始任务保留进度。视口完成后光标待命巡游，只有显式重播重新绘制已完成内容。采用当前视口模型，暂不预扫整个长文档或实现自动滚动。
- **录制与导出**：原生阶段独立设计录像管线，与重画状态分离；明确是否包含控制条、输出尺寸、帧率、格式与存储位置。浏览器原型的 `getDisplayMedia` / `MediaRecorder` 实现可以验证流程，不能替代原生编码、窗口捕获和权限验证。

## 捕获与交互边界

| 验证项 | 通过条件 |
| --- | --- |
| 排除自身 | 捕获结果不含 BeeBuild 的遮罩、光标或控制条；反复重播不产生镜像嵌套。 |
| 原位覆盖 | 首帧、窗口边界与动画层一致；外部窗口遮挡时不把其他窗口误绘成目标内容。 |
| 滚动跟随 | 用户操作真实滚动区域；连续和惯性滚动均持续推进动画，新增区域增量加入，位置跟随内容移动；不能等待滚动停止才恢复光标。 |
| 36 光标 | 正常播放时保持 36 个光标的存在感；施工与待命运动均由同一时钟管理，显式暂停后全部冻结，完成区域不会自动闪白重播。 |
| 滚动与暂停 | 暂停时仍允许滚动并更新几何，但不能推进绘制进度；继续时从保留进度接续，不补播暂停期间的时间。 |
| 点击策略 | 明确采用透传还是拦截，避免用户点击尚未显现的控件时意外执行底层操作。不能把「动画层不接收事件」描述为「仅滚轮透传」。 |
| 控制条 | 可暂停、调速、重播、录制、退出；操作控制条不切换绑定目标，也不被用于重画的目标截图重新捕获。 |
| 快捷键 | 真正注册系统全局唤起；检测占用与注册失败，允许修改和恢复默认。退出始终有清晰入口。 |
| 内容改变 | 目标刷新、切换文档、滚动区重排时，旧任务不得继续绘制到新位置；无法可靠匹配时重新采集当前视口。 |

`NSWindow.ignoresMouseEvents` 会让窗口对鼠标事件透明，不能单独区分滚轮与点击。`NSEvent` 全局监视器异步观察事件，不能修改或阻止事件送达；不能用它实现可靠的点击拦截。若产品需要选择性拦截，必须另行验证事件处理与权限方案。[窗口事件透明](https://developer.apple.com/documentation/appkit/nswindow/ignoresmouseevents)、[全局事件监视器](https://developer.apple.com/documentation/appkit/nsevent/addglobalmonitorforevents%28matching%3Ahandler%3A%29)

AX 并非所有应用都提供完整属性或通知。ScreenCaptureKit 的 `dirtyRects` 也只是重画、移动区域的并集，不是文档滚动坐标。滚动时的区域识别和像素匹配属于 BeeBuild 自己的算法，必须测试惯性滚动、固定栏、嵌套区域及视频等持续变化内容。对无法稳定匹配的区域重新采样时，也要保持其余有效任务和光标时钟连续；如实际能力不足，应明确记录该应用的限制，而不是把「停稳后重新开始」算作连续滚动通过。[AX 通知限制](https://developer.apple.com/documentation/applicationservices/1462089-axobserveraddnotification)、[变化矩形](https://developer.apple.com/documentation/screencapturekit/scstreamframeinfo/dirtyrects)

## 窗口生命周期与显示环境

- [ ] **关闭目标窗口 / 目标进程退出**：停止捕获与动画，移除遮罩，控制条返回待选窗口状态。
- [ ] **最小化 / 恢复**：目标不可见时挂起捕获并隐藏覆盖层；恢复后重新测量和捕获，避免沿用旧尺寸。系统生命周期挂起与用户的暂停选择分开保存，恢复时保留原播放意图。
- [ ] **移动 / 调整大小 / 跨屏**：跟踪真实位置与可见区域；拖动期间不留下残影，不遮住错误窗口。
- [ ] **Retina 与混合缩放**：明确区分屏幕点、捕获像素与渲染坐标；跨屏后重新读取比例，验证文本边缘与矩形落点。
- [ ] **多显示器 / 全屏 / Spaces**：只在目标所在空间与屏幕显示，不全局置顶遮挡其他工作；目标不可见时隐藏并管理捕获生命周期，不改写用户的暂停选择。
- [ ] **弹窗与子窗口**：检测其出现并决定暂停或明确纳入捕获，不能假设单窗口过滤器自动包含弹窗。
- [ ] **遮挡**：窗口捕获虽可提供被遮挡目标的完整内容，动画层仍应遵循可见窗口关系；避免盖住用户新打开的前台应用。

Apple 说明：独立窗口捕获可跨显示器并保持目标内容；被遮挡时仍输出完整窗口，最小化时流暂停；单窗口过滤不自动包含该应用的弹窗或其他窗口。[ScreenCaptureKit 窗口行为](https://developer.apple.com/videos/play/wwdc2022/10155/)

## 权限、异常与交付门槛

- [ ] **屏幕录制权限**：未授权时不开始遮罩；拒绝后仍能退出并重试，明确说明权限只为读取选定画面。不要承诺所有系统版本都无需重启或重新打开应用。[Apple 捕获示例](https://developer.apple.com/documentation/screencapturekit/capturing-screen-content-in-macos)
- [ ] **辅助功能权限**：单独检查信任状态；拒绝时保留截图重画能力，禁用依赖 AX 的增强。系统提示是异步过程，不把弹出提示当作已经授权。[AX 信任检查](https://developer.apple.com/documentation/applicationservices/1459186-axisprocesstrustedwithoptions)
- [ ] **受保护或不可捕获内容**：若来源不给画面、产生空帧或捕获错误，应提示当前内容不可用并恢复原窗口；不尝试绕过保护，不把黑屏当作完成效果。
- [ ] **捕获中断 / AX 卡住 / 权限撤销**：采用超时与取消机制；所有失败路径优先移除遮罩，不留下阻塞用户的窗口。
- [ ] **后台与恢复**：切换应用、锁屏和显示器变化后不累积过时时间或过期任务；回到目标时重新验证窗口身份。
- [ ] **减少动态效果**：支持隐藏移动光标与较轻的区域显现，遵循用户设置；不依赖动画才可操作控制条。
- [ ] **性能**：在支持的 Mac 和系统版本上实际记录帧率、CPU/GPU 与内存；覆盖 36 光标、长文、密集列表、持续视频、快速滚动、频繁缩放及同时录制。分别记录静止施工、连续滚动与录制状态，不能只测空白待命画面。
- [ ] **本地处理**：默认不上传窗口内容，不持久保存重画用截图；视频仅由明确的录制操作产生，并提供预览、保存与丢弃路径。临时文件在丢弃、错误或退出后得到清理。

## 录制与导出验收

- [ ] **来源与范围**：录制前明确当前窗口或用户选择的范围；与动画捕获源分开管理，避免录到无限镜像或其他未选窗口。
- [ ] **独立控制**：暂停重画时录制仍继续；结束重画与停止录制的行为有清晰提示，不默默丢失视频。
- [ ] **用户结束共享 / 来源关闭**：可完成已有有效数据或明确报告中断，释放捕获和编码资源；不能一直显示正在录制。
- [ ] **格式与预览**：按真实编码器能力确定输出容器与扩展名，下载后可播放；明确首版是否提供 GIF，不能把视频文件改名为 `.gif`。
- [ ] **异常与空间**：处理编码失败、磁盘写入失败、无有效帧和较长录制的资源占用；出错后仍可退出或重新开始。
- [ ] **权限分离**：说明原生屏幕捕获权限与浏览器共享对象选择的差别；不将浏览器内已成功录制作为原生授权通过的证据。

交付前必须在真机验证至少一个原生文档应用、一个浏览器长页及一个自绘界面。逐字效果与元素识别能力以实际应用暴露的信息为准；产品应承诺「把看到的内容重画出来」，不要承诺任意应用都有完全相同的 DOM 级重建质量。
